# 사진 추리 v3 — 사진을 만들기 전에 짜는 문제 10개

지금 사진들의 문제: 장면이 고정관념 그대로다(새벽 식당의 남자는 정말 트럭 기사). 그래서 사진을 안 봐도 맞고, 사진을 봐도 "확인"일 뿐 추리가 아니다.

**v3 원칙: 사진의 첫인상은 틀린 답이어야 한다.** 한눈에 보이는 이야기(표면)가 있고, 구석의 작은 단서 2~3개를 엮으면 그 이야기가 무너지고 다른 결론(진실)만 남는다. 셜록 홈즈가 왓슨을 처음 보고 "아프가니스탄에서 오셨군요"라고 한 것과 같은 구조다. 햇볕에 탄 얼굴 + 군인 자세 + 뻣뻣한 팔 → 각각은 아무것도 아니지만 셋을 엮으면 하나만 남는다.

문항 구조는 5개가 한 줄로 이어지는 추리 사슬이다. Q1~Q4는 작은 결론 하나씩(각각 다른 단서 조합), Q5가 최종 결론. 정답은 다 풀고 한꺼번에 공개하니 사슬이어도 된다. 다만 **각 문항의 글만 보면 '표면 이야기' 쪽 보기가 더 그럴듯해야** 한다.

사진 제작 때 지킬 것:
- 결정적 단서 2~3개는 1080px 원본에서 확대하면 또렷이 보이게(작아도 되지만 흐리면 안 됨). 미끼 단서 1~2개는 크게.
- 글자는 최소화(AI가 글자를 망침). 숫자·간판이 꼭 필요하면 짧게, 생성 후 확인.
- 구도는 표면 이야기가 먼저 읽히게. 단서는 구석·반사·그림자·바닥에.
- 생성한 뒤 단서가 실제로 보이는지 확인하고, 안 보이면 그 문항을 바꾼다(지금 사진에서 가장 많이 터진 문제).

## 1. 공항 도착장의 남자 — "아프가니스탄에서 오셨군요"
*영감: 코난 도일 『주홍색 연구』 홈즈의 첫 추리*

**상황 글:** 오후 2시, 인천공항 도착장. 햇볕에 그을린 40대 남자가 혼자 서 있다. 이 사람은 누구일까?
**표면:** 휴양지에서 돌아온 여행객(그을린 피부, 면세점 쇼핑백).
**진실:** 중동 건설 현장에서 1년 가까이 일하고 귀국해, 마중 없이 지방 집으로 가는 길.

**사진에 심을 것**
- 얼굴·목·팔뚝 짙게 그을림. 손목에 시계 모양 하얀 띠, 왼손 약지에 반지 자국 하얀 띠(둘 다 선명). 이마 위쪽에 안전모 선(모자 선과 다르게 이마 한가운데가 하얗게 경계).
- 폴로셔츠·면바지는 새것(포장 접힌 주름이 가슴·허벅지에 남음, 소매에 실밥). 발은 흙·시멘트 가루 묻은 안전화.
- 손: 굳은살, 손톱 밑 때, 손등 작은 흉터.
- 낡은 더플백에 수하물 태그(경유지 코드 3글자 하나만 또렷, 예: DOH). 면세점 쇼핑백 하나(화장품 상자).
- 시선은 리무진 버스 시간표 전광판. 주변은 가족과 포옹하는 사람들.

**문항**
1. 어디서 돌아오는 길일까? — 동남아 휴양지 / 유럽 배낭여행 / **중동 공사 현장** / 미국 출장
   단서: 안전화 + 안전모 선(선글라스 자국이 아니라 이마 경계) + 태그 경유지.
2. 얼마나 오래 있었을까? — 일주일 / 한 달 / **반년 넘게** / 이틀
   단서: 시계·반지 자국이 하얗게 남을 만큼 깊은 그을림(짧은 여행으론 안 생김) + 낡은 가방 + 짧았다 자란 머리.
3. 지금 입은 옷은? — 늘 입던 옷 / 회사 작업복 / **방금 산 새 옷** / 빌린 옷
   단서: 포장 주름·실밥 + 신발만 안 바꿈(새 옷에 안전화).
4. 누가 마중 나왔을까? — 아내 / 회사 사람 / 부모님 / **아무도**
   단서: 혼자 시간표를 봄 + 선물 쇼핑백을 아직 들고 있음 + 주변 가족들과 대비.
5. 이다음 어디로 갈까? — 시내 호텔 / 회사 사무실 / **고속버스로 지방 집** / 다시 출국장
   단서: 리무진 시간표 + 반지 자국(가족 있음) + 면세 선물.

## 2. 눈 오는 밤의 현관 (거짓말)
*영감: 고전 추리 퀴즈 "눈 위의 발자국"*

**상황 글:** 밤 11시 40분, 단독주택 현관. 남편에게 저녁에 뭐 했냐고 묻자 이렇게 말했다. 사진 속에서 거짓말을 찾아라.
**진술:** "저녁 내내 집에 있었어요. 아내가 8시쯤 편의점에 잠깐 다녀왔고요. 저는 밤새 문밖에 안 나갔습니다. 눈은 10시쯤 그쳤죠."
**표면:** 눈 쌓인 조용한 현관, 발자국 한 줄 — 아내가 편의점 다녀온 자국처럼 보임.
**진실:** 남편이 눈 오는 중에 나갔다가 눈이 그친 뒤 돌아왔다. 거짓말은 "밤새 안 나갔다".

**사진에 심을 것**
- 현관 밖 눈밭. 큰 부츠 자국 두 줄: **나가는 방향 자국은 눈에 반쯤 덮여 희미**, **들어오는 방향 자국은 또렷**(눈이 그친 뒤 생김). 여자 신발 자국은 없음(8시 자국은 덮였으니 모순 아님 — 미끼).
- 현관 안: 남자 부츠 젖어 바닥에 물, 여자 부츠는 말라 있음. 두 부츠 바닥 무늬가 다르게 보이게(밖의 자국은 남자 것과 같은 무늬).
- 창밖 맑은 밤하늘, 담장 위 눈 두께 고름(그친 지 한참). 벽시계 11:40.

**문항**
1. 사진과 맞지 않는 말은? — 저녁 내내 집에 있었다 / 아내가 8시에 편의점 / **밤새 문밖에 안 나갔다** / 눈은 10시쯤 그쳤다
2. 눈은 언제 그쳤을까? — 아직 오는 중 / 방금 그쳤다 / **몇 시간 전** / 어제 그쳤다
   단서: 희미한 자국과 또렷한 자국의 차이 + 맑은 하늘 + 고른 눈 두께.
3. 바깥 발자국의 주인은? — 아내 / **남편** / 택배 기사 / 이웃
   단서: 자국 무늬 = 현관의 남자 부츠 무늬 + 그 부츠만 젖음.
4. 그 사람은 언제 나갔다 들어왔을까? — 눈 그친 뒤 나가 아직 안 옴 / **눈 올 때 나가 그친 뒤 돌아옴** / 눈 그치기 전에 왕복 / 눈 그친 뒤에 왕복
   단서: 나가는 자국만 덮임.
5. 얼마나 나가 있었을까? — 5분 / **한 시간 넘게** / 밤새 / 안 나갔다
   단서: 한 자국만 덮이려면 눈이 한참 더 와야 함 + 부츠 안까지 젖음.

## 3. 셀카 속 반사 (거짓말)
*영감: 2019년 일본 아이돌 스토커 사건 — 눈동자에 비친 역 간판으로 집을 찾아냄. 요즘 '사진 한 장으로 위치 찾기' 뉴스*

**상황 글:** 토요일 오후, 친구가 보낸 셀카 한 장과 메시지. 사진 속에서 거짓말을 찾아라.
**진술:** "나 지금 제주도 호텔이야. 혼자 왔어. 방금 도착했어. 비 와서 방에만 있어."
**표면:** 호텔 방 셀카, 혼자 찍은 듯.
**진실:** 혼자가 아니다. 거짓말은 "혼자 왔어".

**사진에 심을 것**
- 호텔 침대에 앉은 셀카. 선글라스를 머리에 올렸거나 쓴 상태 — **선글라스 알에 비친 사람 실루엣**(촬영자 아닌, 맞은편에 선 남자).
- 테이블에 커피잔 **둘**, 하나는 립스틱 자국 없음.
- 참인 단서: 창에 빗방울 + 흐린 창밖(비 참). 캐리어 닫힌 채 세워져 있고 키카드 봉투가 침대에(방금 도착 참). 벽 액자나 수건에 호텔 이름 짧게 + 창밖 돌담/야자수(제주 참).
- 미끼: 침대 베개 하나만 눌림(혼자처럼 보임).

**문항**
1. 사진과 맞지 않는 말은? — 제주도 호텔이다 / **혼자 왔다** / 방금 도착했다 / 비가 온다
2. 지금 방 안에는 몇 명일까? — 한 명 / **두 명** / 세 명 이상 / 아무도(비어 있는 방을 찍음)
   단서: 선글라스 반사 + 잔 둘.
3. 도착한 지 얼마나 됐을까? — **한 시간 안** / 반나절 / 하루 / 며칠
   단서: 닫힌 캐리어 + 키카드 봉투 + 정돈된 침대.
4. 사진 속 다른 사람은 어디에 있을까? — 복도 / 욕실 / **창가 맞은편** / 침대 옆
   단서: 반사의 위치와 빛 방향(창을 등지고 섬).
5. 그 사람은 누구일까? — 호텔 직원 / 룸서비스 / **같이 온 일행** / 옆방 손님
   단서: 잔 둘 다 마신 상태 + 편한 차림 실루엣(유니폼 아님) + 의자에 걸린 두 번째 겉옷.

## 4. 짖지 않은 개 (범인)
*영감: 코난 도일 「실버 블레이즈」 — "그날 밤 개는 짖지 않았다"*

**상황 글:** 아침 7시, 단독주택 뒷마당. 창고에서 자전거가 사라졌다. 아버지는 "도둑이 담을 넘었다"고 한다. 범인은 누구일까?
**표면:** 열린 창고, 도둑.
**진실:** 이 집 아들이 새벽에 열쇠로 창고를 열고 자전거를 타고 나갔다.

**사진에 심을 것**
- 창고 문 열림. 자물쇠는 **멀쩡히 열린 채** 고리에 걸려 있고 열쇠가 꽂혀 있음.
- 흙바닥 발자국: 집 뒷문 → 창고로 이어지는 **슬리퍼 자국 한 줄**(작은 사이즈). 담 아래 잔디는 이슬 맺힌 채 흐트러짐 없음.
- 개집 앞 대형견이 태평하게 자고 있음, 옆에 **뜯긴 간식 봉지**.
- 창고 안: 자전거 자리만 먼지 없이 깨끗, 벽 걸이의 **헬멧도 없음**(빈 걸이), 공구는 그대로.
- 뒷문 살짝 열림, 2층 창 커튼.

**문항**
1. 침입자는 어디로 들어왔을까? — 담을 넘어 / 대문으로 / **집 안에서 나와서** / 창고 뒤 창문으로
   단서: 담 아래 이슬 잔디 멀쩡 + 뒷문에서 시작하는 자국.
2. 자물쇠는 어떻게 됐을까? — 부서졌다 / 원래 안 잠겨 있었다 / **열쇠로 열렸다** / 바꿔치기됐다
   단서: 멀쩡한 자물쇠 + 꽂힌 열쇠.
3. 개는 왜 짖지 않았을까? — 늙어서 / 묶여 있어서 / **아는 사람이라서** / 그 자리에 없어서
   단서: 간식 봉지 + 태평한 잠 + 자국이 개집 바로 앞을 지남.
4. 자전거 말고 또 없어진 것은? — 공구 상자 / **헬멧** / 아무것도 / 사다리
   단서: 빈 걸이(공구는 그대로) → 훔친 게 아니라 타러 감.
5. 범인은? — 동네 좀도둑 / 이웃집 남자 / **이 집 아들** / 아버지 본인
   단서: 작은 슬리퍼 자국 + 열쇠 + 개 간식 + 헬멧.

## 5. 깨진 유리의 방향 (무슨 일)
*영감: 보험 사기 수사의 고전 — "유리는 힘을 받은 반대쪽으로 떨어진다"*

**상황 글:** 아침 8시, 작은 금은방 안. 주인이 "새벽에 누가 밖에서 돌을 던져 유리를 깨고 들어와 금고를 털었다"고 신고했다. 무슨 일이 있었을까?
**표면:** 깨진 유리문, 열린 빈 금고 — 강도.
**진실:** 안에서 깬 자작극. 침입자는 없었다.

**사진에 심을 것**
- 가게 안쪽에서 본 깨진 유리문. 유리 조각은 **대부분 바깥 보도에** 흩어짐, 안쪽 바닥엔 거의 없음.
- 돌은 바깥 보도에 있고, **돌 위에 유리 조각이 얹혀 있지 않음**(유리가 먼저 깨진 뒤 돌이 놓임).
- 안쪽 바닥: 먼지·발자국 없음, 진열장 유리 멀쩡, 진열품 그대로.
- 금고: 문 열려 있고 비었지만 **긁힘·파손 없음**(번호로 열림), 금고 앞 바닥 깨끗.
- 미끼: 카운터 위 엎어진 의자, 흩어진 서류(어질러진 척).

**문항**
1. 유리는 어느 쪽에서 깨졌을까? — 밖에서 / **안에서** / 양쪽에서 / 저절로
   단서: 조각이 바깥에 + 돌 위에 조각 없음.
2. 침입자가 안으로 들어왔을까? — 들어와서 나갔다 / 들어와 아직 있다 / **들어온 적 없다** / 뒷문으로 들어왔다
   단서: 안쪽 바닥에 유리 가루·발자국 없음 + 진열장 멀쩡.
3. 금고는 어떻게 열렸을까? — 부수고 / 열쇠를 훔쳐서 / **번호를 아는 사람이** / 원래 열려 있었다
   단서: 흠집 없음 + 바닥 깨끗.
4. 어질러진 서류와 의자는? — 격투 흔적 / 도둑이 뒤진 것 / **일부러 어지럽힌 것** / 바람에 넘어진 것
   단서: 서류 위에 유리 조각 없음(유리 깨지기 전에 흩어짐) + 다른 곳은 멀쩡.
5. 무슨 일이 있었을까? — 강도 침입 / 직원의 내부 범행 / **주인의 자작극** / 단순 파손 사고
   단서: 위 넷의 합.

## 6. 지하철 분실 가방 — 주인은 누구 (누구인가)
*영감: 코난 도일 「푸른 카벙클」 — 모자 하나로 주인의 삶을 읽는 장면*

**상황 글:** 오후 3시, 지하철 역무실. 주인 없는 가방을 열어 내용물을 책상에 펼쳤다. 주인은 누구일까?
**표면:** 큰 검정 백팩, 야구 모자 — 젊은 남자 것처럼 보임.
**진실:** 새벽에 급식실에서 일하고 오후에 퇴근하던 일곱 살 아이의 엄마.

**사진에 심을 것**

## 7. 벽에 남은 액자 자국 (무슨 일)

## 8. 그림자 시계 (거짓말)

## 9. 할머니 집의 손님 (무슨 일)

**진실:** 방학을 맞은 손주가 오전에 와서 며칠 묵는 중이고, 지금 안방에서 낮잠 자고 있다.

**사진에 심을 것**
- 탁자: 찻잔 하나 + **작은 유리컵(우유 자국)**, 과자 부스러기, 크레용과 그림 여러 장.

5. 얼마나 머물까? — 저녁까지 / **며칠** / 지금 바로 간다 / 알 수 없다
   단서: 캐리어·꺼낸 옷 + 칫솔 둘 + 달력 '방학'.

## 10. 현관 앞에 쌓인 것들 (무슨 일)
*영감: 지자체 '우유 배달 안부 확인' 사업 뉴스 — 쌓인 우유로 이상을 알아챈 사례*

**상황 글:** 오전 10시, 빌라 2층 복도. 어느 집 현관 앞에 물건이 쌓여 있다. 이 집에 무슨 일이 있을까?
**표면:** 신문·우유가 며칠 치 쌓임 — 여행 가서 집을 비웠다.
**진실:** 사람은 집 안에 있다. 다만 며칠째 문밖에 못 나오고 있다(아파서). 안부 확인이 필요한 상황.

**사진에 심을 것**
- 문 앞: 신문 3부(날짜가 사흘 연속, 숫자 짧게), 우유 3개, 전단지.
- 사람이 있다는 단서: **문 아래 틈으로 새는 불빛**, 현관 옆 작은 창에 **김 서림**(안이 따뜻함), 문 앞 화분 흙이 젖어 있음(최근 물 줌), 문고리에 **오늘 날짜 약 배달 봉투**(수령 안 됨).
- 혼자 사는 노인 단서: 지팡이 걸이, 전단지에 노인용 서비스, 우유 작은 것.
- 미끼: 문 옆 접힌 유모차/캐리어? → 넣지 말 것. 대신 옆집 문 앞엔 아무것도 없음(대비).

**문항**
1. 물건은 며칠째 쌓였을까? — 하루 / **사흘** / 일주일 / 한 달
   단서: 신문 날짜 + 우유 개수.
2. 집 안에 사람이 있을까? — 여행 중이라 없다 / 이사 갔다 / **있다** / 알 수 없다
   단서: 불빛 + 김 서림 + 젖은 화분 흙.
3. 누가 사는 집일까? — 젊은 부부 / 학생 / **혼자 사는 노인** / 아이 있는 가족
   단서: 지팡이 걸이 + 전단지 종류 + 약 봉투.
4. 약 봉투는 언제 걸렸을까? — 사흘 전 / 어제 / **오늘** / 일주일 전
   단서: 봉투 날짜 + 그 위에 전단지가 안 덮임 + 신문 더미 위에 놓임.
5. 이 집 상황은? — 여행 중 / 이사 준비 / **안에 있지만 나오지 못함** / 비어 있는 집
   단서: 위 넷의 합 — 사람은 있는데 사흘째 문 앞 물건을 못 들임.
